    Privacy, supported formats, and known limits
    
        Privacy and redaction
        
    
          
      
        • Everything runs in this page. There are no network requests, no uploads, no telemetry, and no external resources.
          • 
      
        • Raw scan text and unredacted previews are never stored. Redaction runs before anything is saved; only redacted results reach local storage.
          • 
      
        • Redaction is best effort. It recognizes common labels (VIN, chassis, license plate, registration, serial numbers) and 17-character VIN-like strings. Identifiers in unknown shapes may remain — review previews and exports before sharing.
          • 
      
        • Titles, vehicle nicknames, tags, and notes pass through the same redaction before they are stored. Drawing a code from an import never creates links or scripts.
          • 
    
        
    
        Supported import formats (first version)
        
    
          
      
        • Text: VCDS-style "Address 01: Engine" headers, "[Module]" headers, numeric "code - description" lines, and five-character P/B/C/U fault codes. Duplicate codes are collapsed with an occurrence count.
          • 
      
        • JSON: an array of fault objects or an object with a faults array. Optional title, vehicle, notes, and tags are accepted and redacted; unknown fields are ignored and identifier-style keys (vin, plate, serial, and similar) are dropped entirely.
          • 
      
        • Unknown layouts may parse incompletely. A zero-fault result is a warning, not a clean bill of health.
          • 
    
        
    
        Comparison
        
    
          
      
        • Faults are grouped by module and code. "Absent" describes only the two logs you selected: it does not prove a repair, and it is not a safety or completeness assessment.
          • 
    
        
    
        Local storage
        
    
          
      
        • If storage is blocked or full, the notebook keeps changes in memory and says so visibly instead of pretending to save.
          • 
      
        • Limits: 5 MB total stored data; 250 sessions; 500 fault entries per session; 120-character titles; 4,000-character notes; 32-character tags.
